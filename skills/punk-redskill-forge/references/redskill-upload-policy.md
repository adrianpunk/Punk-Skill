# REDSkill upload policy reference

This reference records the official Xiaohongshu Skill-upload notice observed on 2026-08-23. Read the current official notice and live upload form before submission; they prevail if anything changes.

## Expected standard

- Describe the actual function clearly and truthfully; provide original, useful work.
- Declare each requested permission and its purpose. Request nothing outside the function's scope.
- Keep code and Agent instructions transparent. Users should be able to obtain the stated result from the declared behavior.
- Respect authorship, licences, and rights in code, prompts, styles, names, and media.

## Do not submit

- Skills that automate or operate a Xiaohongshu account, including automatic note publishing and automatic comment replies.
- Illegal or harmful services, including gambling-odds analysis, prohibited-image generation, or restricted-information distribution.
- Claims that exaggerate functionality, or prompts that secretly change Agent behavior beyond what the user expects.
- Malicious code or instructions that collect credentials, Cookies, local data, or other sensitive material.
- Hidden functions that induce an Agent to act beyond the stated capability.

## Practical implications

An adapter may create a copy, an audit, and transparent documentation. It must not call a package compliant merely because no regex matched. Any uncertain external call, binary, dependency, licence, or permission request requires human review. The final platform review is outside the adapter's control.
