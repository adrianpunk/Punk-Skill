# 文字、路径、颜色与装饰

读所选风格后，用本文件把视觉特征落实到本期标题。以下尺寸是起稿区间，允许按字数、字宽、照片空间和实际生成效果调整；不是字体软件字号或点击率保证。

## 尺寸口径

- `W/H` 是目标画布宽高。3:4 的 `S=W`；其他比例默认 `S=min(W,H)`，避免横版按全宽放大字。
- 单字高指可见字身高度，和描边、底托、发光、花体卷曲分开计算。
- 字组外包高包含断行、弧线起伏、倾斜与大小跳跃。标题区还需要留白，不能拿单字高代替标题区高。
- 风格卡的字高范围以 3:4 的 `% W` 记。非 3:4 先按同样的 `% S` 起稿，再依布局调整。1080×1440 中 10% 对应约 108 像素字身，不等于字体字号 108。

| 文字任务 | 起稿参考 | 使用方式 |
|---|---|---|
| 轻记录、真实口播、小衬线标题 | 约 4–11% S | 原照片主导，对比与留白帮助阅读 |
| 一般主标题、品牌、型号 | 约 11–21% S | 一到两行，字组和人物错开 |
| 冲击短词、窄长手绘字 | 约 25–38% S | 仅在少字或压缩字宽的风格中用；先留清楚人脸 |
| 标签、页眉、辅助图注 | 约 2–6% S | 不承载唯一的关键承诺；可按缩略图增大或省略 |

长标题先分出主题词和结果句，按语义断行。用户给出的完整标题保留逐字内容，可把其中关键词做大，其余组织为另一层；不自行删字或添加另一句夸大口号。只有主题时可以提炼真实、简短的封面标题。第二层未必总小：上下两组短词可以共同组成主标题。

## 字形与字效

字形骨架：粗黑体／无衬线、圆鼓手绘、窄长展示字、毛笔笔刷、衬线、细字。按所选风格决定粗细、宽窄、笔触和规则程度，不伪称某款确切字体。

字效分开编译：

- 填色：字身的颜色；可在同一字组内按语义区分重点。
- 描边：沿字形的窄轮廓。起稿可试字高 2–4% 的细边、5–10% 的外边，再按可读性调整。
- 底托：字组背后的连续贴纸、纸牌或色块；起稿可试字高 10–20% 的外留边。底托可以跨字连接，不能用窄描边冒充。
- 空心：内部露出背景，轮廓仍须清楚；窄长空心字需要较大的字身。
- 厚度与投影：前后感；方向和光线统一。使用一套主效果，辅助字避免叠满效果。

保护中文结构。斜排、弯排、手写不等于缺笔、粘字和变成无法辨认的字符。

## 颜色角色

先按 [照片四色](photo-palette.md) 提取 C1–C4，再分配背景、主文字、强调和辅助用途。多色衬线可按语义分配这四个色族，不逐字随机换色。风格参考色值只表达角色，本期实际配色来自上传照片及其明度／饱和度派生值。

区分照片色和设计色：提取四个基础色是全部风格的要求，服装色优先但可从照片其他区域补足。人物肤色、头发、衣服及内容素材保留自然细节，不强行重染成四色；原环境默认被抠图移除，不是默认背景。

先看文字背后的背景是否复杂或低对比，再决定加轮廓、加底托、换位或压暗。浅色拼贴允许柔和，但核心标题仍要能读；辅助小字不抢主字。

## 路径与层次

| 路径 | 编译时落实 | 要点 |
|---|---|---|
| 上拱 | 短词围在头顶，整字沿切线轻转 | 先排词再做曲线；脸在拱下 |
| 下弧 | 字组两端高、中间低，浅 U 形收尾 | 放在手势下方或胸腹空区 |
| 侧边阶梯 | 语义短行宽窄错落，人物靠另一侧 | 不是机械竖排每个字 |
| 跳跃散放 | 字或词填人物周围空隙，大小与角度变化 | 顶部主题＋两侧／底部动作词，读序明确 |
| 前后遮挡 | 后方问题或背景词 → 人物 → 前景完整关键词 | 关键读法完整；让出眼鼻嘴 |
| 沿道具弯排 | 小短句依镜头、键盘或产品轮廓走 | 道具主标题分层，不能长句整圈缠绕 |
| 标题牌倾斜 | 标题与载体整组轻旋转 | 不把各字随机扭转成另一套路径 |
| 场景透视 | 整词近大远小，一起向同一方向消失 | 增大人像后再安排场景；中文用短主题 |
| 分格／VS | 标题贴每格空区，过程与结果有对应关系 | 一格明确为主人物，另一格给场景／结果 |

弧线起伏可先试约 4–10% S，按短词、头部空间与风格力度调整。沿路径移动旋转与字形透视变形是不同操作；中文优先保留完整字形。完整圆环只在适合短文字、用户要求或构图确有空间时采用，不设为默认。

## 人物与字的空间

先决定最大焦点是人、一个词还是产品，再保留另外两者的辨识度。允许前景字压肩胸、头发遮少量后字；眼睛、鼻尖、嘴部及关键道具保持清楚。背景大字不能成为唯一完整信息却被挡得读不出。

3:4 正面半身人物可先试占画宽 55–85%，侧置先试 45–65%；普通人脸宽可先试 22–38% W。大脸口播、微缩人物和拼贴按本期独立调整。默认全部风格都用真人抠图，但位置、景别、朝向和是否描白边由本期构图与材质决定，不默认居中。

## 装饰按功能选择

| 功能 | 可选物件 | 使用理由 |
|---|---|---|
| 引导阅读 | 箭头、弯线、圈画、虚线、VS | 连接手势、过程和结果，指向实际焦点 |
| 强化情绪 | 星芒、放射线、问号、感叹号、爆炸线 | 放在脸外或词尾，呼应语气 |
| 识别内容 | 主题图标、产品图、作品窗、标签 | 对应主题或人手正在展示的对象 |
| 建立材料 | 撕纸、胶带、相框、贴纸边、纸张纹理 | 服从同一拼贴／手帐材料语言 |
| 审美气氛 | 银花、缎带、镜面、蝴蝶、雕塑 | 适合冷银／浪漫风，给文字留下净区 |
| 统一纵深 | 速度线、科技线框、碎片、光线 | 服从场景视角和主动作 |
| 主题巨物 | 放大产品、微缩场景、造型道具 | 作为内容和环境，先定与人物的关系 |

口播可零装饰，轻记录可一颗星，拼贴与漫画可以较密。去掉后不损失主题、读序、情绪或材料质感的装饰，优先删。不要把所有主题元素都用上。
