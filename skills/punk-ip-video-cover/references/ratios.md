# 四种比例的重排

只输出用户请求的比例。默认 3:4；尺寸可作为提示词目标，工具实际尺寸必须检查，不能声称工具支持未提供的 size 参数。

| 比例 | 可选目标尺寸 | 编排起点 |
|---|---|---|
| 3:4 | 1080×1440 | 短主题词在上，人脸居中或侧置，结果句在胸前／下方；也可两三格生活叙事 |
| 16:9 | 1920×1080 | 人物与文字左右错开；曲线可移到人物所在的一侧；产品前景与标题区平衡 |
| 4:3 | 1440×1080 | 较紧凑的左右构图或横向三角关系；少字大标题可上排，结果或产品在下 |
| 9:16 | 1080×1920 | 人物偏上中，标题与结果上下分层；增加场景长度而非无限放大人和字 |

字体尺寸优先按短边 `S=min(W,H)` 计算。纵向照片的上下黑边不作为设计元素继承；新画布应填满目标构图。画幅变化重新确定断行、路径、人物景别、道具与装饰，不拉伸原图。

## 保留机制，调整位置

- 上弧：横版仍围在人物头顶，但不横跨全部画宽；另一侧可放完整结果词。
- 下弧：靠近托举动作或主体下缘，保持短句；横版可改为人物一侧的浅弧收尾。
- 侧边字：竖版用短行阶梯，横版可以更宽的侧边信息区，但不增加无用文字。
- 前后遮挡：后方大字—人物—前方关键词的层次保留，前景载体按比例变宽或变紧凑。
- 微缩人物／前景产品：先定产品和人像大小，再找标题留白；避免横版时人物丢失。
- 分格：3:4、9:16 可上下二到三格；横版可左右二格或一主图加辅格。至少一格给主人物。
- 场景透视：整词与环境保持统一消失方向；横版有更宽纵深，竖版用更短的词并增大人物。

边缘余量可先试短边的 4–6%；实际平台叠加图标和裁切需按已知界面预览，不称作官方统一安全区。字、脸、关键产品不贴边。
