# 人物、动作与主题物

身份照片决定本期人物的身份特征，不是动作或表情锁定图。用户已允许按主题修改动作与表情，适用于全部风格：可调整身体姿态、手势、朝向、视线与情绪，不需要每次另问。具体动作由本期主题、构图空间与风格决定，不要求每张都改或每次张嘴惊讶。用户明确要求原姿态／原表情不变时，以该次要求为准。持物和场景仍依用户输入及风格规则处理。不能把采集案例中的人作为身份输入；不能因为风格说明提到多个时刻，就自动生成第二个陌生人物。

## 保留和可变部分

默认从原照片环境中抠出真人作为独立摄影主体，再安排本期背景与自由构图；不默认保留原景色。抠图不等于强制白边，轮廓处理依材质和人物与背景的分离程度。用户当次明确要求原环境时再保留。

- 保留可辨认的脸型、五官比例、发型和人物整体识别特征；眼镜与标志性配件默认保留，用户要求另行处理时执行。
- 动作与表情是可变部分；保留稳定脸型、五官相对比例和整体辨识度，允许表情带来的自然肌肉变化，不能改成另一个人。
- 默认沿用服装款式和颜色；能否改变服装或原手持物取决于所选风格和用户要求。允许动作与表情重设计，不等于默认换装或替换道具。
- Y2K 风格明确保留原服装、手持物和身体比例；没有用户覆盖要求时保持这一局部规则。其服装取色限制不扩展到其他风格。
- 气质描述依照片可观察内容，不推测照片人物姓名、职业或其他身份。名字只用用户输入。

## 按主题决定动作

| 表达意图 | 合适起点 | 内容关系 |
|---|---|---|
| 概念、疑问、反常识 | 思考、轻疑问、指向关键词 | 一个完整关键词与问题，不需要每次惊讶张嘴 |
| 工具介绍、方法、流程 | 托举、摊手、指作品／界面 | 手势有对象，图标或结果贴近动作 |
| 产品评测、开箱、对比 | 向前持物、佩戴、比较两件物 | 展示产品结构，人脸在另一侧清楚 |
| 合集、实测、好物 | 分组展示、举起主题物、轻松分享 | 标题数字与物件数量一致，缺数据不补虚数 |
| 生活、情绪、旅行 | 保留自然表情、行走、记录、生活动作 | 场景与人物状态为主，避免不必要的戏剧化 |
| 创意脑洞、漫画动作 | 坐／站在主题巨物上、向前伸出主题物 | 与承托面、接触阴影、视角建立关系 |

动作与表情是生成设计选择，不对用户宣称研究原图必定由 AI 二创。

## 道具与图像素材

产品、界面或作品可作为本期内容。用户提供真实产品图、作品或截图时，明确其输入角色；准确产品外观重要但素材缺失时，先使用足够把握的描述，必要时询问具体型号或素材。装饰可用通用主题符号，不能把原研究图中的品牌、界面小字、标题和道具无条件照搬。

生活分格需要同一主题片段。用户只给一张人物照片时，可生成同一人物的相关场景，保持身份一致；若用户只允许原照片或真实现有作品，则仅用提供素材或减少格数，不虚构“真实拍摄成果”。

检查修改后的表情是否自然、是否仍是同一人物，不把笑容大小或姿势改变直接判为失败。检查肩颈、双手、手指数量、物件接触、前后大小与光线。向前展示物品时，手和产品共享近大远小；微缩人物有承托面与接触影。脸不能小到失去个人 IP 识别；奇观风格也需保住主角优先级。
