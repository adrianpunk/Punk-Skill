# 人物视频封面提示词蓝图

蓝图提供完整封面的形状；风格的 `PROMPT.md` 提供视觉语言。填写为一份具体、融合的封面说明，删除不适用段落，不保留未填写占位符，也不把原始文档整个附在后面。

## 需要落实的信息

| 部分 | 本次具体内容 |
|---|---|
| 任务 | 一个独立封面、使用比例、主题、版本与所选风格 |
| 输入角色 | 哪张是唯一身份照片，哪些是用户提供的本期产品／作品素材；不传研究参考图 |
| 可见文字 | 视频标题逐字内容，以及实际使用的背景大字、名字、辅助短句；未使用的字段省略 |
| 人物 | 原图中可辨识特征、保留内容、所选风格要求的处理方式、裁切与占比 |
| 核心处理 | 真人抠图作为独立主体，本期自由构图，不继承风格范例坐标或原照片背景 |
| 动作与表情 | 用户已允许按主题修改；具体写出本版姿态、手势、朝向与情绪，保留身份特征，不把原动作和原笑容自动列为锁定项 |
| 风格落地 | 关键字形、色彩逻辑、人物处理、背景结构、材质与装饰，具体写出它们出现在何处 |
| 排版 | 人物区、标题区、背景区、对齐轴、断行、层级、留白、前后关系与面部保护区 |
| 文字参数 | 单字高与字组区分、宽窄、描边／底托／空心／厚度、路径、弧线起伏、前后遮挡 |
| 配色 | 从本期照片四色出发，用所选风格决定明暗、面积、材料与对比分工，不继承固定色值 |
| 照片四色 | 逐项列 C1–C4 的实际颜色与照片来源，再分配背景／文字／强调／辅助角色；四色是基础色族，派生色注明，不另添无来源基础色 |
| 主题元素 | 动作、表情、道具、装饰及位置，分别写清与本期主题的关系；不套整套装饰清单 |
| 输出标准 | 文字准确、人物关系合理、风格锚点可见、阅读顺序明确、实际比例匹配 |

## 多版本

每个版本单独编译；同照片共享提取的四个基础色，可改变用色面积和角色。风格字形、材质和装饰不串用，真人抠图与自由构图共用；明确每版排版差异。不得为了“做出差异”擅自改标题、服装或新增结果数据。

## 生成提示词的清理

从风格元数据与视觉原子编译本次规则，所有花括号字段填写后删除不适用的行。标题按本期白名单逐字列出；不留目录文字、来源信息、研究观察、博主名或风格编号作可见内容。只在标题或用户明确提供的名字里使用相应词，不能从风格说明例子自动提取新文案。
