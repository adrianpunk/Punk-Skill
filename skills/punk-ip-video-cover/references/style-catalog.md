# 人物 IP 封面风格目录

当前共 25 种已接入风格：用户提供的 Y2K、服装取色真人撕纸拼贴，加 23 个经授权提炼的设计方向。全部支持 3:4、16:9、4:3、9:16；默认 3:4。文件接入状态为 active，实际生成效果尚未逐套验证。

此目录仅含名称与规则，不显示或附带参考图。选择后只读本次风格的 STYLE.md / PROMPT.md，不读取外部研究画廊。字体名没有来源验证时使用字形类别；风格名字不是要写进封面的标题。

## 按主题路由

| 意图 | 优先候选 |
|---|---|
| 小白解释一个术语 | giant-sticker、green-dialogue、calm-talking-head |
| 工具带来一个明确结果 | floating-tools、brush-sidebar、paper-collage |
| 实测／清单／几件好物 | jumping-doodle、arc-brand-lineup、arc-impact |
| 手机／耳机／相机新品 | foreground-product、glass-tech-type、minimal-profile-product |
| 拍摄／制作的过程与效果 | outline-versus、paper-collage、segmented-diary |
| 一天生活／轻记录／旅行 | white-handwritten-record、segmented-diary、film-editorial |
| 精致／浪漫／冷银审美 | silver-floral-collage、pastel-sticker |
| 成长／情绪／自然观点 | colorful-serif、calm-talking-head、brush-sidebar |
| 城市／目的地／空间主题 | perspective-location、white-handwritten-record、film-editorial |
| 创意脑洞／主题巨物 | comic-poster、spectacle-props、scale-remix |
| 人物衣服有明显主题色、年轻手绘感 | y2k-pop-editorial、jumping-doodle、pastel-sticker |
| 服装取色、复古纸面、真人剪贴，构图可切换 | wardrobe-paper-collage |

结合照片的景别、侧边空间、动作可用程度与用户语气再选，不按主题词机械套样式。例如“AI”也可以是安静口播，不必总有图标；生活也可以用冲击手绘，只要内容适合。

自动制作选一个后继续；先让用户选时提供最多三个文字候选；出多个版本时，保持人物／文案／比例一致，优先在字形、路径和人物关系上形成差异。用户要五套时输出五版，不自动乘四比例。只要方案／改 skill 时不出图。

## 新风格维护

新风格使用独立目录，按 [接入规则](add-style.md) 处理。发现用户新加风格但目录尚未更新时，检查其文件和来源用途后补索引；不复制其参考图片进成品或分发包。已有 Y2K 的源文字保留于其 SOURCE.md，仅核对歧义时读取，不当生成输入。
