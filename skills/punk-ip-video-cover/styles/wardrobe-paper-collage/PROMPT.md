# 服装取色·真人撕纸拼贴：视觉原子

> 执行优先级：先从上传照片提取四个代表色并搭配、抠出真人、按本期主题自由构图，再应用本风格字形与材质。下文的参考色值、原背景处理和固定位置只作例子，不覆盖共用核心；见 [照片四色](../../references/photo-palette.md) 和 [基础构图](../../references/layouts.md)。

把本文件编译成具体封面提示词；只使用本期真人身份照片和文字，生成时不传风格参考图。图像范例中的标题、数字、服装字样及小卡片内容不是本期输入。

## 材质语言

复古哑光纸面拼贴。背景是一整张有轻纤维、色差和磨损的有色纸；标题置于暖白不规则撕纸上；真人是一层摄影剪贴；主题素材可放在独立纸片窗内。各层有轻薄接触影，呈现剪下、贴上、叠放的物理感，不能做成光滑 UI 面板或厚重三维浮雕。粗糙感集中在纸边与少量墨痕，面部保持清晰。

## 从本期真人服装派生色盘

1. 选择衣服中最突出、可辨识且有足够面积的色彩，不以肤色、头发、墨镜或照片环境取主色。深色衣服有大片彩色图案时优先该图案；不是取一个孤立亮点。如果衣服只有黑白灰，采用石墨灰／暖灰纸底加暖白纸，强调色依用户主题选择并说明为备用色，不凭空宣称服装有彩色主色。
2. **背景色**：保留主色的色相，将明度压至中暗、饱和度稍收，形成厚纸或印染纸的底色。服装颜色鲜艳时保留色相特征，不能一律压成脏灰。主体与底色太接近时用更暗背景或暖白纸片隔开，不给人物衣服重新染色。
3. **纸面色**：暖白或淡象牙，承担大标题、人物剪纸边和内容窗口；可轻带主色色温，仍与背景明显分离。
4. **墨色**：近黑炭墨，放暖白主标题纸上；强调纸带上的字一般用暖白或近黑，按明暗对比选，细字不用低对比同色。
5. **强调色**：从主色的互补／分裂互补或协调邻近色中选择一个。采用哑光印刷的中高饱和版本，负责可选副标题纸带或少量视觉标记，避免第二种大面积背景与人物争抢。
6. **胶带与次级素材色**：米黄、浅灰或主色的浅淡版本，服从同一色温。设计角色通常 4–5 个，真实肤色和原服装图案不被重染限色。

配色示例只说明派生关系：绿色衣服可用深橄榄背景、象牙纸、炭墨、铁锈红强调；蓝色衣服可用深靛蓝背景、暖白纸、炭墨、杏橙强调；黄色图案可用赭金背景、奶油白纸、炭墨、深蓝强调。每次从当前照片重选，不自动套任何示例。

在本期提示词中写出突出色的衣服来源、实际色盘及各自用途；不要把“根据衣服配色”作为未落实的空指令。

## 中文字形与字效

主标题：极粗手工切字／刻印展示字，偏方块并适度压缩字宽，端点略不齐，少量缺口与墨色磨损。完整汉字结构必须清楚，不能像普通黑体仅整体旋转，也不能把笔画拆散成拼字。关键词可有大小节奏；语义断行优先，基线轻微起伏。整体纸片可倾斜约 2–5°，不是每个字随机转角。短主词字身可为 24–30% S，正常多字标题为 14–22% S，按净区调整。

副标题：只有用户给出或本期主题明确需要时采用，暖白粗窄无衬线或较规整手工字，放强调色撕纸带；字身约 5–9% S，与主标题建立明显主次。无副标题时省略纸带。

标题字通常不加大描边或立体挤出，暖白纸已承担底托；墨面可有轻纹理。纸片形状、字高、行间距及边距按本次构图匹配，不要硬规定顶部两行或副标题横跨全幅。

## 真人剪贴与层次

本期真人保留摄影皮肤、可辨认五官、发型、眼镜与服装。动作、朝向和表情可以按主题重设计，包括自然微笑、开心、疑问、思考或适度夸张的情绪；保留稳定身份特征，不套同一种笑容。外缘是一圈暖白不规则剪纸边，可从人物可见宽度约 1–2% 起稿，轻薄接触影；不是卡通轮廓线。脸、身体保持真实比例，不继承小人的头身比，不把照片画成油画。纹理放在纸层，不能覆在脸上改变五官。

选定基础结构后决定人物位于何处、半身或全身、朝向与占比。需要指向、托举或展示动作时再根据主题设计，不默认复制参考动作。真人剪贴可盖住纸片非关键边缘，标题纸可压肩胸，但不能遮五官或主要关键词；面部与手要有净区。可选主题卡片位于基础结构预留的信息区，不默认右侧网格。

## 内容拼贴与装饰

主题需要时用产品、作品、示意小图或抽象内容卡片作纸片拼贴，数量由内容决定；不照搬参考的八个应用示意。图示内容要对应当前主题，品牌、数字、界面文字只来自本期输入。没有相关素材时让人物与标题承担信息，不能虚构作品或证明结果。

选少量能建立材料或动线的装饰：一到两处半透明米色胶带固定纸片，短放射墨线强调手势或关键词，少量折痕或撕边强调拼接。纸边本身已经是主要装饰，文字密时先删贴纸与射线。不强制剪刀、花卉、棕榈、星爆或底部大纸带。

## 编译顺序与检验

先确定本期身份、标题白名单、基础构图与比例；再落实服装色盘、真人纸边、标题字形和纸层；最后按主题添加可选纸带及内容卡片。说明每块纸片的位置与前后关系，不附参考案例图。

检查：真人仍可辨认；主色确来自本期衣服；背景与人物有分离；剪纸边和接触影统一；汉字完整；主辅文字明暗清楚；主题卡片有内容依据；当前结构来自基础构图库，没有自动复制左人右八宫格。出图状态如实记录，未生成不能标为效果通过。
