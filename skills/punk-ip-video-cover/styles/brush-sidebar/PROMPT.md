# 笔刷关键词＋侧边错落短句：视觉原子

> 执行优先级：先从上传照片提取四个代表色并搭配、抠出真人、按本期主题自由构图，再应用本风格字形与材质。下文的参考色值、原背景处理和固定位置只作例子，不覆盖共用核心；见 [照片四色](../../references/photo-palette.md) 和 [基础构图](../../references/layouts.md)。

把以下规则编译为本期完整封面说明，不直接把此文件当成已经填写的生成提示词。只使用用户人物与本期文字；不需要参考案例图片，不输出目录名称、编号或规则说明。

## 构图与文字路径

人物在右或左侧；另一侧为主笔刷关键词和按语义下降的中文短行；底部下划线收尾。

## 字形、字高与效果

连笔英文笔刷＋中文毛笔。主字身约 22–32% S；第二层文字约 14–22% S。字身尺寸与字组占区、外边和底托分开。关键词和中文有笔刷粗细、飞白与不齐基线；以黄色下划线收尾，白色主句不额外套巨大贴纸边。 保留完整中文结构，主句先按语义排清楚再做弯曲或倾斜。小字只承载辅助信息。

## 颜色逻辑

亮黄关键词、白色短句、较暗暖背景；可按主题换成一强调色加统一主句色。 这里的颜色是设计角色，不把人物肤色、衣服和原环境强制限色。用户指定配色优先，仍保持本风格的明暗、材料和重点分工。

## 人物与主题物

工作、讲解、侧向看字、轻指向；原身份与服装保留，动作可配合标题。 保留本期身份照片的脸、发型和标志性特征；道具和动作仅服务本期主题，手与物件的接触、近大远小、光线一致。主标题可压肩胸，五官保持清楚。

## 装饰

手绘划线、短放射线、少量星芒；不需要一圈软件图标。 只选有识别、引导、情绪或材料作用的元素；每项在提示词里有明确位置。文字长或场景复杂时减装饰。
