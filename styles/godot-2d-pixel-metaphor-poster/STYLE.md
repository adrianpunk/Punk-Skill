# Godot 2D 像素隐喻海报

## 视觉风格原子

创作一张具有思想表达的 Godot 2D 独立游戏像素风视觉隐喻海报。不要把主题文字直接画成插图；先理解文字背后的观点、情绪、冲突与隐藏含义，再把它转化成一个玩家仿佛可以亲自体验的游戏关卡，用一个强烈、清楚的机制隐喻表达主题。

## 主题理解

- 在内部提取主题的表面含义、深层含义、核心冲突、主要情绪和最适合视觉化的关系，但不展示分析过程。
- 一张图只表达一个最重要的观点，不试图容纳主题的所有信息。
- 按“抽象概念 → 具体场景 → 游戏机制 → 视觉隐喻”的顺序完成转译。场景必须让观众感到这是一种可以被玩家体验的处境，而不是一组解释性图标。

## 游戏机制隐喻

- 方向冲突：用反向道路、传送带、移动平台、错误箭头或消失终点表达努力方向错误、越努力越远或追逐错误目标。
- 距离关系：用远方城堡、山顶、出口、阶梯或桥梁表达遥远目标、时间积累和长期主义。
- 尺度反差：用微小角色面对巨大机器、巨塔、城市、系统或怪物，表达人与 AI、时代或规则的关系。
- 循环困境：用循环道路、无限楼梯、重复房间或闭环地图表达内耗、重复劳动和无法突破。
- 光暗对比：用黑暗空间中的单一光源、出口、火焰或森林入口表达希望、觉醒和选择。
- 建造与积累：用城堡、图书馆、基地、升级结构或资源积累表达知识、成长、复利和长期价值。
- 信息与注意力：用数据洪流、通知怪物、安静森林或隐藏区域表达 AI 时代、信息洪流和专注力。
- 这些是关系词典，不是固定模板。先内部构思多个方向，最终只选择最容易理解、最有视觉冲击、最适合单张海报且最有情绪反差的一个隐喻。

## 单一场景与构图

- 画面必须只有一个主要角色、一个明确动作、一个核心象征物、一个目标或阻碍、一个视觉焦点和一块合理留白。
- 不增加第二主角、第二主要隐喻或复杂支线故事。环境可以丰富，但所有地形、建筑、道具和光源都必须服务同一个机制关系。
- 可使用左文字右场景、上文字下场景、中心压迫、远近距离、对角线运动或环形循环构图；依据主题和比例选择一种，不平均混合。
- 成品应像真实存在的独立游戏宣传海报：具有完整世界观、环境叙事和关卡空间，但不是游戏截图、概念草图、普通插画或 UI 界面。

## 比例适配

- `16:9` / `3:2` 横版：强化左右关系、横向移动和完整世界景深，让角色与目标形成清楚距离，标题进入留白区或场景结构。
- `4:5` / `9:16` 竖版：强化上下空间、攀登或坠落路径，把目标放在远方或上方，标题位于顶部、中上区域或垂直地形中。
- `1:1` 方形：集中为一个中心符号或闭环关卡，缩短阅读路径并强化缩略图识别度。
- 自定义比例：重新设计标题位置、角色比例、场景空间、视觉动线和留白。禁止把固定横版模板直接裁切到其他比例。

## 标题与场景融合

- 用户输入的主题原文必须完整、准确地至少出现一次，使用清晰可读的中文或英文像素字体，并保持海报级排版。
- 文字不能浮贴在场景上。标题可以成为建筑、道路、关卡边界、远方目标、光源、可破坏地形或环境符号，也可以被机械局部遮挡、产生受控像素故障，或与角色动作发生关系。
- 从主题原文选择 1–3 个关键词，通过放大、改色、错位、破碎、发光、阴影或像素化形成第一层冲击，但不能损害完整原文的可读性。
- 除主题原文外不增加大量说明文字、随机英文、日期、版本号、品牌、Logo 或虚构游戏信息。

## Godot 2D 像素语言

- 呈现为 Godot 制作的独立游戏二维像素艺术：手工逐像素绘制感，16-bit / 32-bit 视觉密度，清晰硬边像素，统一 Sprite 比例，Tilemap 环境和真实关卡设计逻辑。
- 角色、环境、标题、地形、粒子和阴影必须共享一致的像素网格与分辨率逻辑；不能混合不同像素尺度、平滑矢量边缘或高分辨率照片元素。
- 使用像素艺术内部的电影级光影、景深分层、雾气、局部光源和环境叙事，但保持像素边缘清楚，不使用模糊滤镜掩盖细节。
- 不是给普通图片添加像素滤镜，不是 3D 渲染后降采样，也不是模仿现成游戏的角色、地图、Logo 或具体美术资产。

## 色彩系统

- 根据主题自动选择一套有限、统一且有主次面积的像素调色板，不固定颜色。
- 明亮冒险方向可用蓝天、草地、阳光和清新绿色；暗黑幻想方向可用深蓝、黑、暗红和火光；科技未来方向可用蓝紫、数据光和克制霓虹；温暖成长方向可用黄昏橙光、紫色天空和治愈氛围。
- 色彩必须服务主题和隐喻，不照搬固定游戏配色，也不要让所有颜色平均竞争。
- 参考图中的明亮平台冒险世界、横向关卡和远方城堡是一种代表性实现，不是固定模板；不要复制其 Godot 标识、问号砖、道具槽、菜单面板、角色造型或具体文案。

## 风格特有禁用项

- 不要写实摄影、3D 渲染、普通动漫、矢量插画、商业 PPT、信息图或普通封面模板。
- 不要四宫格、多故事场景、多主角、多主要隐喻、复杂游戏 UI、物品栏、状态栏或菜单界面。
- 不要大量文字、随机英文、水印、Logo、错误中文、模糊像素、平滑滤镜或不统一像素比例。
- 不要复制任何现有游戏的角色、地图、Sprite、Tilemap、图标、Logo、商标或具体关卡。
- 不要让成品看起来像直接截取的游戏画面；它必须具有海报级标题层级、留白和视觉焦点。

## 最终标准

最终画面应像一个真实存在的独立游戏宣传海报：一个可体验的游戏机制隐喻，一个主角与明确动作，一个目标或阻碍，一个完整像素世界，准确主题原文，专业排版，清楚世界观、情绪张力和视觉记忆点。

只生成一张最终图，不输出分析、解释、多个方案、拼图、网格或联系表。
