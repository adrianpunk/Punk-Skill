# 极简轻科技

## 视觉风格原子

创作一张“极简轻科技”封面：干净的纯白 / 暖白 / 浅灰背景、大面积留白、现代超粗黑体标题，以及画面中唯一的一个主视觉锚点。锚点要么是轻微立体化的品牌 Logo，要么是一枚抽象的柔和 3D 玻璃 / 渐变形体；柔和精致的渐变只集中在这个锚点上，不铺满整张画面。整体像高级轻科技产品封面或品牌概念海报，安静、清晰、克制，不要赛博朋克，不要密集 UI，不要拼贴，不要把画面填满。

## 整体风格

- 视觉识别来自四件事：大面积浅色留白、超粗现代黑体标题、单一主视觉锚点、锚点上的柔和渐变。
- 气质是轻科技、产品感、干净、高级、克制；像当代 SaaS / 工具 / 品牌发布封面，而不是游戏海报、营销大促或科幻概念片。
- 平台适配、长文提炼、用途文案和通用封面约束由 `punk-cover` 负责；本 style 只拥有视觉语言本身。

## 画幅与构图

- 画幅比例只用于决定构图，绝不把比例数字、分辨率数字或尺寸标注印进画面。
- 横版（如 5:2、16:9）优先：左侧或偏左放置标题，右侧或偏右放置唯一锚点；也可采用安静的非对称平衡，但必须保留明确呼吸空间。
- 竖版（如 4:5、3:4、9:16）优先：标题在中上区域，锚点在标题下方或一侧，锚点尺寸收敛，不压过标题。
- 正方形可居中或轻微偏侧，但仍然只保留一个锚点，四周留白充分。
- 画面主体只包含：浅色背景、可选标题文字、一个主视觉锚点、极轻的接触阴影。不要第二主视觉，不要装饰边框，不要角落小图标阵列。

## 文字系统

- 当画面文字不是「无文字」时，画面中的可见文字必须与用户给定文案完全一致，不得改写、扩写、翻译或增减字符。
- 当画面文字为「无文字」时，画面中不出现任何标题或说明文字，只保留浅色背景与唯一锚点。
- 中文标题使用现代超粗黑体 / 无衬线黑体，字形饱满、边缘干净、字距自然；颜色为黑色或近黑，不做渐变字、描边字、发光字或立体挤压字。
- 英文若作为标题的一部分出现，同样使用粗体无衬线，并服从同一排版层级；不要额外添加用户未提供的英文副标、口号或水印。
- 标题以清楚易读为准，可醒目但不粗暴占满画面；不要斜排、竖横混排、文字穿过锚点、文字贴边或小字说明堆叠。

## 主视觉锚点

- 整张图只能有一个主视觉锚点。锚点是画面第二焦点（有标题时）或唯一焦点（无文字时）。
- 分支规则：
  - 若「是否提供 logo」为是，并且用户提供了 logo：优先走 Logo 锚点分支。
  - 若未提供 logo，或用户明确偏好抽象形体：走抽象锚点分支。
- 锚点必须轻、净、集中；渐变、高光、半透明和轻微立体感都只发生在锚点内部及其紧邻阴影，不扩散成背景光污染。

## logo 规则

- Logo 需可识别：保留核心图形、比例和品牌识别特征，不要重绘成陌生符号，不要伪造未提供的商标文字。
- 允许轻微立体化 / 轻拟物处理：圆角厚度、柔和高光、细腻接触阴影、轻微玻璃或软塑胶质感均可，但必须克制，不能变成夸张玩具、重金属或赛博徽章。
- Logo 可作为锚点本体，也可被轻轻嵌入一枚柔和的玻璃 / 渐变载体中；无论哪种，仍然只算一个锚点。
- 若 logo 使用说明有指定（位置、原色保留、禁止改色等），严格遵守；未说明时，可在选定渐变色系内做克制的光色呼应，但不得破坏识别。

## 抽象锚点

- 抽象锚点应是一枚柔和的 3D 玻璃体、透镜层叠、半透明椭圆、软流体或精致渐变形体；表面光滑、边缘圆润、通透或雾面通透。
- 形体简洁，通常由一到三层交叠的软几何构成，表达轻科技、透明、流动或能量汇聚；不要复杂机械零件，不要电路板，不要拟物手机 / 电脑整机。
- 锚点下方可有非常轻的漫射接触阴影，以建立落地感；阴影不能重、不能脏、不能拉出长投影戏剧光。

## 色彩与渐变

- 背景固定在纯白、暖白或非常浅的冷灰 / 暖灰；背景本身不做大面积彩色渐变、网格、噪声或光斑。
- 渐变只服务锚点。根据「渐变色系选择」落地：
  - 自动选择：依据内容主题与配色补充说明，优先蓝绿、冰川、银蓝或低饱和冷色等轻科技方向。
  - 蓝绿系：天空蓝 → 青绿 / 青蓝过渡。
  - 蓝紫系：靛蓝 → 雾紫。
  - 紫粉系：雾紫 → 柔粉，保持低噪高级，避免甜俗。
  - 青绿系：湖绿 → 青绿。
  - 薄荷系：薄荷青 → 浅青绿。
  - 冰川系：冰蓝 → 冷白青。
  - 银蓝系：银灰高光 + 冷蓝。
  - 金橙系：暖金 → 柔橙，克制使用，避免廉价促销感。
  - 黑金系：近黑锚点结构 + 金色高光边缘，仍需留白底，不要暗黑整版。
  - 低饱和暖色系：雾杏、暖灰、淡陶色等低饱和暖调。
  - 低饱和冷色系：雾蓝、灰青、鼠尾草绿等低饱和冷调。
  - 其他：严格按配色补充说明执行。
- 配色补充说明用于微调；若与所选色系冲突，以用户补充说明为准，但不得破坏浅色留白底和单一锚点原则。

## 材质与光影

- 材质关键词：柔和玻璃、磨砂液态、细腻渐变塑料、轻拟物、干净棚拍感。
- 光线为明亮、柔和、接近顶光 / 前侧柔光的产品摄影光；锚点内部可有通透高光与轻微折射，但不要强霓虹、不要硬边聚光、不要体积光扫过全画面。
- 阴影只服务锚点落地，保持短、淡、干净。

## 输出目标

- 适合作为科技产品封面、工具教程封面、品牌概念海报、公众号 / X / 视频横版头图，以及需要干净现代感的竖版海报。
- 最终画面应一眼可读：浅色留白 +（可选）超粗黑标题 + 唯一渐变锚点。

## 风格特有禁用项

- 不要赛博朋克、霓虹描边、故障风、粒子爆炸、强发光描边或暗黑科幻装甲。
- 不要密集 UI、仪表盘、代码雨、窗口叠层、信息图、流程图、图标宫格或截图拼贴。
- 不要多个主视觉锚点、多个 Logo、装饰插画人物、复杂场景或把画面填满。
- 不要在画面中写出画幅比例、尺寸数字、水印、提示词原文或用户未提供的说明小字。
- 不要渐变铺满背景、不要彩色大色块争抢标题、不要立体挤压标题、不要书法体 / 圆体 / 卡通装饰字体。
